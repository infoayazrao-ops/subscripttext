How do you add subscript or superscript in Google Docs?

Two ways: Use Format → Text → Subscript/Superscript (Ctrl + , / Ctrl + . on Windows; ⌘ + , / ⌘ + . on Mac), or paste Unicode CO₂ and x² from our generator.

Method 1: Format Menu (Best for Beginners)

This is the clearest way to make subscript in Google Docs if you do not remember shortcuts.

  1. Open your document in Google Docs.
  2. Type the formula in plain text (for example H2O or x2).
  3. Select only the character that should move (the 2).
  4. Click Format in the top menu.
  5. Choose Text, then Subscript or Superscript.

Apply the same path again to turn formatting off before you continue typing normal text. This changes only the selected characters and works well for short formulas in one document.

Common mistakes

  • Formatting the whole word: Select only the digit (the 2 in H2O), not H2O entire.
  • Using Word shortcuts in Docs: Ctrl + = is Word, not Docs. Docs uses Ctrl + , and Ctrl + .
  • Expecting formatting to survive chat: Docs subscript can look normal after paste into WhatsApp—use Unicode from the generator instead.

Google Docs on phone or tablet

  1. Open the Google Docs app and select the digit or letter to format.
  2. Tap the format icon (often an A with lines).
  3. Look under text options for Subscript or Superscript.

If the mobile menu is hard to find on your version, generate Unicode on the phone browser with our tool, copy, and paste into the Doc—that path works the same on mobile and desktop.
