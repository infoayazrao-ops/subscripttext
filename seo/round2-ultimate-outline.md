## 1) Shared architecture (every A–E page)

### Snippet stack (CTR) — title ≠ meta ≠ H1
- **Title (≤60):** primary + secondary benefit (specific: CO₂, Canva no button, Discord tiny…)
- **Meta (~155):** primary *variation* + secondary; conversion copy, not stuffing
- **H1:** primary *3rd variation* \| pain/benefit (visitor retain)

### NLP / passage rhythm (AEO + AI Overviews + Copilot)
Every content H2:
1. **Question or job-shaped heading** (keeps target keywords; improves clarity)
2. **40–60 word direct answer first** (passage ranking / fan-out)
3. Steps, table, or chips
4. **One honest limit** (missing letter, paste break, boxes, Discord one small style)

### Keyword discipline (never remove — place once)
| Slot | Count |
|---|---|
| Primary | H1 + open bar + close CTA only |
| Secondary | 1 H2 + 1 body |
| Tertiary | 1 heading + 1 body |
| Density | ≤ 0.5% exact match |
| Body links | ≤ 2–3 on ~500w; benefit anchors; no cannibal exact-match |

### GEO extractables (must appear as HTML text)
- Comparison / coverage / paste-break **tables**
- U+ code points where useful (digits, missing letters)
- Concrete examples: H₂O, CO₂, x², `-# hello`
- Platform limits: IG bio 150, Discord nick, Canva text box

### Pitch (one line everywhere)
Type plain → real Unicode → copy → paste where there is **no formatting button**.
