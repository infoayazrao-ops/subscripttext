## Pitch and tone (locked for all Round 2 writing)

### Brand pitch (one line)
**“Type plain text → get real Unicode → copy → paste anywhere that has no formatting button.”**

That is the product promise. Every page sells a **workaround**, not a lecture.

### Audience pitches (use the matching one)

| Audience | Pitch |
|---|---|
| **STEM** (chem / math / teachers / Docs / Canva) | Apps don’t make H₂O or x² easy outside Word. We give characters that survive paste into slides, chat, and LMS boxes. |
| **Superscript** (exponents / footnotes) | Need a raised 2 or footnote ¹ that still works after you leave Word. Generate Unicode, or use Ctrl+Shift++ only when the file stays in Word. |
| **Small text / Discord / IG** | Want tiny bio or Discord text. Use Unicode styles **or** Discord’s `-# ` for smaller-than-normal. We say what works and what breaks. |

### Tone (how it should sound)
- **Teacher demo** (YouTube pattern): “Here’s how…”, “For this example, use 2…”, then steps
- **Calm, practical, honest** — not hype, not corporate, not “AI blog”
- **8th-grade reading level** — short sentences, concrete words
- **Second person** (“you type / you copy / you paste”)
- **Proof over adjectives** — show H₂O, x², `-# hello`, U+ codes, missing letters
- **STEM pages:** classroom / lab / worksheet energy  
- **Small-text pages:** friend-showing-Discord energy (still clear, not slang-heavy)

### Structure every section should follow
1. Problem (no button / formatting dies on paste)  
2. Fix (tool mode or shortcut)  
3. Do it (1–4 steps)  
4. Limit (honest: missing letters, one Discord small style, boxes on old phones)

### Do say
- type, select, copy, paste, Unicode, Formula mode, Numbers Only  
- “Word formatting often breaks in WhatsApp”  
- “Unicode has no subscript b / f / q”  
- “Discord `-# ` is smaller than normal text”

### Don’t say
- AI-tell words (delve, landscape, unlock, seamless, dive in, comprehensive guide…)  
- Fake urgency (“game-changer”, “secret”, “ultimate”)  
- Keyword stuffing (“Our Superscript Generator… Superscript Generator…”)  
- Em dashes in prose; long throat-clearing intros  
- Chem formulas on the **small text generator** page (wrong audience)

### Snippet / CTR tone (title + meta)
- Benefit first: free, copy paste, survives chat, no signup  
- Specific outcome: CO₂, H₂O, x², Discord tiny text  
- Not vague: avoid “best powerful online tool for everyone”

## Latest ranking trends (2026) — what actually works

### Google Search + AI Overviews / AI Mode
- Same core helpful, people-first SEO still drives AI features (Google Search Central).
- **Query fan-out:** complex queries split into sub-intents — pages that answer related PAA/fan-out sections get cited more (studies ~161% higher odds when ranking across fan-out set).
- **Passage ranking:** clear 40–60 word answer blocks after question H2s help retrieval.
- **Non-commodity content:** unique POV / first-hand testing beats generic “7 tips” commodity pages.
- **Do NOT chase:** llms.txt as a ranking hack, tiny AI-only chunks, special “AI schema,” fake brand mentions, a page for every long-tail variation (scaled content abuse risk).
- AIO citations often come from **outside classic top-3**; organic + extractable depth both matter.
- Structured data must **match visible text**; HowTo on real steps still useful; FAQ schema ≠ rich-result win.

### Bing + Microsoft Copilot
- Copilot grounds on **Bing index** — verify Bing Webmaster Tools + sitemap; consider **IndexNow** on publish/update.
- Answer-first passages, clear titles/descriptions, crawlable HTML text (not JS-only).
- Bing AI Performance report can track citations (monitor later).

### ChatGPT / Perplexity / other GEO
- Engines **diverge** (~11% domain overlap ChatGPT↔Perplexity in some studies) — one tactic does not win all.
- Shared wins: **direct answers**, comparison **tables**, freshness (`dateModified`), extractable facts, real entity coverage.
- Perplexity: freshness + community sources (Reddit/YouTube) bias — parallel backlink/mention track stays relevant; don’t spam Reddit.
- ChatGPT: often Bing/partner visibility + authoritative clear pages.
- Brand mentions / earned links still correlate with AI visibility more than stuffing FAQ schema.
