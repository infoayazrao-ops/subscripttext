Phone steps (150-character bio limit)

  1. Copy a line above, or type your name in the live bio converter and copy a style.
  2. Open Instagram → your profile → Edit profile → Bio.
  3. Paste. Watch the 150-character counter — tiny letters still count as one character each.
  4. Save with Done or the check mark.

q has no tiny Unicode form. It stays a normal q. That is better than a tofu box in the bio.

Captions use the same paste. The caption box is longer than 150 characters, so a full sentence in tiny letters will fit. Reels and Stories text boxes also accept the glyphs; some stickers still render them as the default UI font, so check the preview before you post.

Discord nicknames are much tighter — only 32 characters. If you also play in servers, see tiny letters in Discord for nickname steps.

On a computer, instagram.com → profile → Edit profile is the same paste. Use the site in a normal browser, not an in-app WebView that blocks the clipboard. If Paste is greyed out, copy the chip again after you focus the Bio field.
