How does this tool make raised Unicode?

You type normal characters. The page maps digits (and supported letters) to Unicode code points that sit above the baseline. Digits ⁰–⁹ and related marks are listed in the U2070 PDF and the names list. Copy the output and you move real characters, not a font switch. Formula mode lifts only digits after letters; Full mode raises every supported character in the box.

Unicode copy paste vs Word Ctrl+Shift++

Ctrl + Shift + + in Word (Command + Shift + + on Mac) only changes how that app draws the digit. Paste the sentence into WhatsApp or email and the 2 often drops flat again. Unicode copy paste puts a different character on the clipboard (² is U+00B2), so chat apps keep it raised. HTML authors can also mark raised text with MDN’s <sup>, but chat boxes need the Unicode glyph itself.

Which superscript letters are missing in Unicode?

Digits 0–9 always map (⁰–⁹). Most Latin letters have a raised form, but q has none. This tool leaves q normal and converts what exists. If a classmate sees a box, their font is missing the glyph; they still received the right code point.

What is the opposite of superscript?

The opposite sits below the baseline (H₂O, CO₂). Superscript sits above (x², ¹). Short compare: below vs above the line.
