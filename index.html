How do I write chemical formulas in subscript?

For chemical formulas like H₂O or CO₂, type plain H2O or CO2, turn on Formula mode and Numbers Only: On. Only digits after letters drop below the line; element symbols stay normal. Need a ready board? See the chemistry formula copy board.

  • H2O → H₂O
  • CO2 → CO₂
  • C6H12O6 → C₆H₁₂O₆

Which letters have no Unicode subscript?

Unicode defines subscript digits (U+2080 to U+2089) and many letters, but not b, f, or q. The tool leaves those letters normal and converts what exists. For B₁-style notation, type B1 with Formula mode instead of expecting a subscript b character.

What is a subscript?

A subscript sits below the baseline, like the 2 in H₂O. It is a Unicode character (U+2080 to U+209C for many digits), not a font style that disappears on copy. Read the full guide: what is subscript (meaning, examples, and when to use lowered digits vs raised exponents).

What is the difference between subscript and superscript?

Subscript is below the line (H₂O, x₁). Superscript is above (x², ¹). Pick Subscript or Superscript on the tool before you copy. Comparison table: below vs above the line.
