Footnote marks ¹ ² ³ in plain text

Footnotes use the same raised set, not lowered chemistry digits. Tap ¹ ² ³ above, paste next to the word, and the mark travels with the sentence. Do not mix ₂ into an exponent; that code point sits below the line.

Ctrl + Shift + = in Word only changes how that app draws a normal 2 (Microsoft’s Word steps). Paste into a message and the 2 often drops flat. ² is a different character, so WhatsApp and Docs keep it up.
