Footnote copy paste (¹ ² ³)

For footnote copy and paste or 1 footnote copy and paste, use superscript ¹, not subscript ₁.

  • Footnote 1 → ¹
  • Footnote 2 → ²
  • Footnote 3 → ³

Type 1 on the superscript generator and copy. Word/Docs shortcuts also work if you stay inside that app: see superscript in Word and Google Docs.

How to use the superscript generator (copy paste)

  1. Open the superscript generator (Superscript is already selected).
  2. Type x2, E=mc2, or a digit for a footnote.
  3. Use Formula + Numbers Only: On if only the exponent should rise.
  4. Click Copy and paste into Word, Docs, WhatsApp, PowerPoint, or email.

You get Unicode, not Word-only formatting, so x² usually survives when you move it between apps. Tiny letters for Instagram are a different tool: the small text generator.

Where exponent copy paste works

  • Microsoft Word — paste Unicode, or Ctrl + Shift + =
  • Google Docs — paste Unicode, or Ctrl + .
  • Excel — Unicode labels like m²; use ^ in formulas for math
  • PowerPoint — paste into a text box
  • WhatsApp — paste Unicode; there is no raised-text button
