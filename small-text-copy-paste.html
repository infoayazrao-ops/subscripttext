When boxes appear

If you shrink “hello” in Word and copy, chat still shows a normal hello. Apps ignore point size. The chips above send real code points, so you should see ʰᵉˡˡᵒ after paste.

  • q has no tiny form. It stays a normal q so you do not get a box.
  • Some fonts draw tiny marks higher or thinner. That is the font, not the app deleting your bio.
  • If you see a box, the device is missing that one letter. Switch to a common system font, or leave the missing letter normal.
  • If Paste is greyed out, focus the text field first, then copy the chip again.
