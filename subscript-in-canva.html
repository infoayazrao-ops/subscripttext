Does Canva have a subscript button?

No. Subscript in Canva means paste Unicode into a text box. There is no toolbar toggle like Word. Generate H₂O or CO₂, copy once, and paste. That is the method that survives export and print.

How to add subscript in Canva with Unicode paste

Canva will not turn a normal 2 into a low digit. You paste a ready character (H₂O, CO₂) into a text box. Those digits live in the Unicode superscripts and subscripts block (see the U2070 PDF chart). Most default fonts keep ₀–₉ readable. Decorative fonts may show a missing-glyph box; switch font and paste again.

  1. Open the free paste tool.
  2. Type H2O or CO2. Keep Formula mode on so only the digits drop.
  3. Click Copy.
  4. In Canva, double-click a text box and paste.

Can you fake subscript in Canva without Unicode?

Yes, as a visual trick only. Split letters into separate text boxes, shrink the digit, and nudge it down. It looks fine in a still mockup, then falls apart when you resize the heading or export for print. Prefer real Unicode when the font supports it. Word’s Format → Subscript is a different path (see Microsoft’s Word guide) and still will not help inside Canva.

  1. Type H in one box and 2 in another, then O in a third.
  2. Shrink the digit’s font size.
  3. Nudge it down with the position controls.

Do not use this for classroom posters you will edit again. One paste of H₂O is faster and stays aligned.

How to add superscript in Canva for exponents

Superscript in Canva works the same way: paste raised Unicode such as x², m², or footnote ¹. There is no Ctrl + Shift + = shortcut. For a ready board of raised digits and letters, use the raised exponents for posters page, then paste into your text box.

Does Unicode paste work in Canva Docs, Presentations, and print?

Yes in a text box on current Canva for designs, Docs, and Presentations. PNG and PDF usually keep the character as drawn text or an outline. Proof the PDF before print. If a template font is decorative, switch to a system-like font first, then paste again.

Chemistry formulas vs exponents in Canva

Chemistry needs low digits (H₂O, CO₂). Exponents and area labels need raised digits (x², m²). Use Formula mode for formulas so letters stay normal. Use superscript mode for powers. Mixing the two in one paste will look wrong on a slide.

Frequently asked questions

How do I add superscript in Canva?

Paste Unicode such as x² or m² into a text box. Canva has no superscript shortcut like Word’s Ctrl + Shift + =.

Why does my ₂ turn into a box?

The font lacks that glyph. Change the Canva font to Open Sans, Arial, or Times, then paste again.

Does paste work in the Canva mobile app?

Yes. Generate on your phone, copy, open the Canva app, tap the text box, and paste. There is still no native button on mobile.
