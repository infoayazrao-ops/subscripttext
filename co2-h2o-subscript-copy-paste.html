Quick answer: Type CO2 or H2O in the formula converter, turn on Formula + Numbers Only, copy CO₂ or H₂O, and paste into Word, Docs, or slides. The lowered 2 is a real Unicode character (U+2082), not a Word-only style that chat apps drop.

What if a letter has no Unicode subscript?

Digits 0 to 9 all exist as lowered characters. Many Latin letters do not. Keep element symbols normal and lower only the counts. If you need a rare letter index, check which lowered letters Unicode actually has before you search for a missing glyph.

Need one digit alone? Use the lowered digit board with U+ codes.
