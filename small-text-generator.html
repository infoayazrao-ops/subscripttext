Which small text style should I use?

  • Tiny — smallest look for Instagram bios and Discord chat.
  • Small Caps — compact capital letters.
  • Tiny Subscript — letters sit slightly lower.
  • Wide — spaced letters for a bio headline.
  • Circled — each letter in a circle.

Tips so tiny text actually shows

  • Some older phones or custom fonts show a box (□) for rare glyphs. Try the default system font.
  • Instagram bios and Discord nicknames accept Unicode; a few games or forms strip special characters.
  • This is not a smaller font size. If an app “normalizes” text, tiny letters may revert.
  • Keep bios short. Tiny Unicode is harder to read at long lengths.
  • Not every letter has a tiny Unicode form (q is a common gap). Those letters stay normal so you do not get a box.
