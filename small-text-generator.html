Instagram bio and Discord nickname limits

Platform caps matter before you paste. Instagram bios allow 150 characters. Discord server nicknames allow 32 characters. The meters above update as you type — each tiny letter still counts as one character, so a long aesthetic line can hit the cap faster than you expect.

  • Instagram (150): Edit profile → Bio. Captions and comments have more room, but bios are the tightest field.
  • Discord (32): Edit Server Profile or your global display name. Keep nicks short — one circled word can use half the limit.
  • TikTok: No hard bio cap like Instagram, but tiny text is harder to read at long lengths. Keep captions short.

Which small text style should I use?

  • Tiny — smallest look for Instagram bios and Discord chat.
  • Small Caps — compact capital letters for a headline line.
  • Tiny Subscript — letters sit slightly lower (still social text, not chemistry).
  • Wide — spaced letters for a bio headline.
  • Circled — each letter in a circle; uses characters quickly on Discord.

Tips so tiny text actually shows

  • Some older phones show a box (□) for rare glyphs. Try the default system font.
  • Instagram bios and Discord nicknames accept Unicode; a few games or forms strip special characters.
  • This is not a smaller font size. If an app “normalizes” text, tiny letters may revert.
  • Keep bios short. Tiny Unicode is harder to read at long lengths.
  • Not every letter has a tiny Unicode form (q is a common gap). Those letters stay normal so you do not get a box.
