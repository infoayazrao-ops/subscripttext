Instagram bio and Discord nickname limits

Platform caps matter before you paste. Instagram bios allow 150 characters. Discord server nicknames allow 32 characters. The meters above update as you type. Each tiny letter still counts as one character.

  • Instagram (150): Edit profile → Bio. Captions have more room; bios are the tightest field.
  • Discord (32): Edit Server Profile or your global display name. Keep nicks short.
  • TikTok: Tiny text works in captions, but long lines are hard to read. Keep them short.

Discord -# vs Unicode tiny text

Discord chat has a native trick: type -# then a space, then your words. That line shows smaller than normal. It is not the same as # / ## / ### headings. Nicknames still need Unicode paste. Full steps: Discord chat and nickname paste.

Which letters show as boxes or squares?

  • Some older phones show a box (□) for rare glyphs. Try the default system font.
  • Not every letter has a tiny Unicode form (q is a common gap). Those letters stay normal so you do not get a box.
  • A few games or forms strip special characters. Bios and Discord nicknames usually keep them.
  • This is not a smaller font size. If an app “normalizes” text, tiny letters may revert.

Frequently Asked Questions

What is a small text tool?

It converts normal letters into Unicode tiny letters you can copy and paste. People use it for Instagram bios, Discord names, and TikTok captions.

How do I make tiny text for Instagram?

Type your bio here, click Copy on a style, then paste into Edit profile → Bio. Stay under 150 characters. Instagram has no tiny-font button.

Does tiny text work in Discord?

Yes. Paste Unicode into a message, nickname, or channel topic. Nicknames are limited to 32 characters. For chat-only size, Discord also supports -# with a space.

Is this a smaller font?

No. The output is Unicode characters you paste like normal text. Apps have no tiny-font button; this is the usual workaround.

Can I use this on TikTok?

Yes. Paste into captions or comments. Display depends on the device font, but most current phones show the tiny letters.

Why does a letter stay normal?

Unicode does not define a tiny form for every letter (q is a common example). Unsupported letters stay unchanged so you do not get a missing-glyph box.

Is this free?

Yes. Free in the browser, no signup, works offline after the first load.

Is the output Unicode or a font file?

Output is Unicode characters, not a downloadable font and not HTML. Paste it like any other text into your bio or chat.
